# 新しい人の作り方

`fish-kit` の `making/`、文鳥の `making/` と同じ考え方です。写真は Codex（OpenAI）の画像生成で作り、Python のスクリプトが写真から形と GLB を作ります。Blender は要りません。

魚と鳥は横からの写真 1 枚でしたが、人は横から見ると腕が体に重なるので、**正面・後ろ・横の 3 枚**を使います。正面が輪郭と幅、横が奥行きと横顔、後ろが背中の模様です。

## 用意するもの

- Codex CLI（画像生成が使える ChatGPT の契約）
- Python 3（numpy・scipy・Pillow）、bash

コマンドはこのフォルダー（`making/`）で動かします。写真は `refs/` に、できた人は `../public/` にできます。

## 手順

| # | すること | 見ること |
|---|---|---|
| 1 | `scripts/humangen/gen_refs.sh` の `PERSON`（どんな人か）を書き換えて `bash scripts/humangen/gen_refs.sh front_a front_b front_c`。正面の候補が 3 枚できる | 全身が入っているか。腕が体から離れ、手のひらが前を向いているか。両脚の間に背景が見えるか。背景が緑一色か |
| 2 | 選んだ正面を見せて、同じ人の後ろ・横・顔の拡大を作る：`FRONT=front_c bash scripts/humangen/gen_refs.sh back side head_front head_side` | 同じ人・同じ服か。横は顔が**左**を向いているか。後ろは正面と同じ腕の開きか |
| 3 | `python scripts/humangen/overlay.py <写真> x0 y0 x1 y1 倍率 目盛り` で目盛りつきの拡大図を作り、関節や顔の位置を写真の画素で読む | 正面は頭・肩・手・脚、横は頭と全身、顔の拡大 2 枚 |
| 4 | 読んだ位置を `humangen.py` の `PEOPLE` に書く（下） | |
| 5 | `python scripts/humangen/humangen.py <名前>` | `logs/<名前>_analysis.png`（輪郭と、関節ごとの重みの境目）、`_side.png`（横から読んだ前後の縁）、`_back.png`（正面の輪郭に合わせた後ろ写真）、`_relief.png`（形に光を当てた図）、`_atlas.png`。出力の `uncovered_px`（肌の穴。数個以下） |
| 6 | アイテムの確認ページで全方向から見る：`node ../scripts/capture.mjs shape face poses` → `python ../scripts/sheets.py` | 顔が正面・斜め・横で人に見えるか。立ち姿で腕と手が自然か。姿勢ごとに関節がおかしくないか |

## `PEOPLE` に書くもの（写真の画素。x は右、y は下。正面写真では画像の左がその人の右）

- `height`：身長（m）。頭のてっぺんから床までがこの長さになる
- `cx`：体の中心の x
- `neck`：頭の重みが 0 の高さ `y0`（えりの上）と 1 の高さ `y1`（あごの下）、首の軸 `pivot`
- `arms`（画像の左の腕から）：`cut` = わきの下 → 肩のてっぺん（この線の外が腕）、`S`・`E`・`W`・`tip` = 肩・ひじ・手首・中指の先
- `spine`：背骨の重みが 0 の高さ `y0`（腰）と 1 の高さ `y1`（肋骨の下）、軸 `pivot`
- `hips`：脚の重みが 0 の高さ `y0` と 1 の高さ `y1`（股のすぐ上）、股関節 `joints`、左右を分ける幅 `split`
- `knees`・`ankles`：高さ `y`、ぼかす幅 `blend`、左右の x
- `face`：目 `eyes` と大きさ `eye_r`、鼻の先 `nose` と幅 `nose_half`、口の両端 `mouth`、あごの下 `chin`、細かいメッシュにする範囲 `box`、耳を分ける線 `ears`（髪の上端 → あごの線。線の外が耳）
- `match_y`：正面と横で同じ高さになる所の組（目・鼻の先・口・あごの下・えりの上）。`(正面の y, 横の y)`
- `side_marks`（横写真）：足首の x `axis_x`、腕の中心線 `arm`（肩・ひじ・手首・指先の `(y, x)`）、鼻の始まりと終わり `nasion_y`・`subnasale_y`、耳の中心 `ear`、細部を残す範囲 `face_y`・顔の中央だけに載せる範囲 `detail_y`
- `side_use`：横写真を模様に使ってよい高さ（頭と首、手より下の脚。その間は腕が体を隠している）
- `power`：断面の角ばり（1 = だ円、小さいほど四角い）、`gain`：腕と手の厚み
- `head_marks`：顔の拡大写真での同じ目印（正面：両目・口・髪のてっぺん・あご。横：鼻の先・耳・髪のてっぺん・あご）

## しくみ

- 輪郭：正面写真の緑の背景を抜く。数画素しかないすき間（太ももの間、指の間）は少し広げる
- 厚み：輪郭の中で ∇²h = −4 を解き、√h を使う（fish-kit と同じ。円は球に、帯は丸い棒になる）
- 奥行き：魚と鳥は厚みに倍率を掛けるだけだったが、人は横写真から各高さの「前の縁」と「後ろの縁」を読み、その行のいちばん厚い所がそこへ届くように行ごとに伸ばす。これで横から見た輪郭が横写真と同じになる（胸・腹・尻・ふくらはぎ・靴）
- 顔：行ごとに伸ばすと、横顔の凹凸（まゆ・鼻・唇・あご）が頭をぐるっと回る輪になってしまう。なだらかな形だけを行全体に使い、細かい凹凸は顔の中央だけに載せる（鼻は細く、唇とあごは広く、へこみは狭く）。目のくぼみは小さなへこみ
- 耳：頭の幅に入れると、耳の高さで頭が太り、耳たぶの下で段になる。耳は線で分けて、1cm ほどの薄いひだにする
- 腕と手：横写真では体に重なるので、丸い棒（手は平たく）にして、横写真で読んだ中心線に置く
- 前後の面：前の面と後ろの面を別に作り、輪郭でつなぐ。つなぐ「縁」は輪郭から取った点かどうかではなく、三角形の端にあるかどうかで決める（内側の点が端に出た所で 2 枚が口を開け、向こうが透けたため）
- 法線：三角形からではなく形の式から求める（文鳥と同じ）
- 高さ合わせ：正面と横の写真は、同じ人でも鼻やあごの高さが数画素ずれる。横顔を 1cm 下に載せた顔は明らかにおかしいので、`match_y` の組で横写真を行ごとに引き伸ばし、正面の行に合わせてから読む
- 後ろ写真：左右を反転し、行ごとに、正面の輪郭の帯（腕・胴・腕、脚・脚）へ引き伸ばして合わせる
- 顔の拡大：全身写真の頭は縦 190 画素しかないので、顔だけ別に撮った拡大写真を、両目（横は鼻の先と耳）で位置を合わせて頭に貼る
- 頂点の属性：`_W0` = 背骨・頭・腕・ひじ、`_W1` = 前腕のねじり・手・脚・どちらの脚か、`_W2` = ひざ・足・横写真を使う度合い・あご
- テクスチャ（2048×2048）：上段に正面・後ろ・横の全身、下段に顔の拡大（正面・横）。ビューアーは形の位置から貼る場所を計算する（`extras.human.tex`）

## 気をつけること

- 人は腕を体から離した A ポーズで、**手のひらを前**に向けて撮る。手のひらと手の甲が写真に写り、立たせるときは前腕をねじって手のひらを太ももへ向ける（`src/villager/rig.ts` の `STAND`）
- 髪は短く。長い髪は肩にかかって首が回せなくなる。すそや袖が大きく広がる服も、関節で折れて見える
- 肩の線（`cut`）は、わきの下の少し上から肩のてっぺんの少し内側へ引く。腕が切り離せないときはエラーで止まる
- Codex には画像を作らせるだけで、保存はさせない（作った画像は `recover_refs.py` が拾う）
- 画像生成で作る人物は架空の大人にする。実在の人の写真は使わない
