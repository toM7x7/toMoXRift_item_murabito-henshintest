VRMA は動き（モーション）のファイルなので、見た目は変えられない。このため選択肢には入れなかった。

## しくみ

1. 村人の前のござ（`Interactable`）をクリックした人が、着る人になる。誰が着ているかは `useInstanceState` で部屋に共有する（1体に1人）
2. 全員の画面が、描く直前（`scene.onBeforeRender`）に、着ている人のアバターの骨格を探して読む。探し方は姿勢ラボの `selectActorRig`（`src/pose-lib`）を使う
3. 描いている間だけ、そのアバターのメッシュ（その骨格で描くもの、骨に付いている髪や帽子）を `visible=false` にする。描き終わったら（`onAfterRender`）元に戻す
4. 骨の向きを村人の姿勢に直して、同じ場所に村人を描く（`src/wear.ts` → `Rig.applyFollow`）

骨は読むだけで、書き換えない。本体が持っているもの（骨・見た目・カメラ）を描画の外で変えることはない。

### 骨の向きを村人の姿勢に直す

- **骨の向き**：各骨の今の向きを「骨のワールド回転 × 休みの姿勢での回転の逆 × 体の軸（restBasis）」で求める。休みの姿勢がTポーズでもAポーズでも、体の軸（左・上・前）で比べられる
- **骨盤・背骨・頭**：体の軸どうしの相対回転をそのまま使う（骨盤は向いている方向に対して、背骨は骨盤に対して、頭は胸に対して）
- **腕**：胸の軸から見た上腕・前腕の向きと、手の指・手のひらの向きを使う。肩はひじの曲がる面で決める。腕がまっすぐなときは肩は振るだけにして、手のひらの向きは前腕のねじりと手首で出す
- **脚**：足首の位置を目標にして、村人の脚の長さで解く。つま先の上げ下げは足の骨の向きから取る
- **大きさ**：村人をアバターの目の高さに合わせて伸び縮みさせる。一人称のカメラが村人の目の位置に来る
- **一人称**：本人の画面では村人の頭を描かない（`discard`）。鏡（描画の中の描画）には映す

## 確かめ方（手元）

- 確認ページ `?lab&wear` に、自分と A さんの代わりの木のマネキンを置いてある。`window.__villager.avatar(id,{motion})` で体操の姿勢を取らせられる
- `node scripts/capture.mjs wear`：着る・やめる・一人称・他の人が着る・部屋を出る（15項目）
- `node scripts/wear-keys.mjs`：体操の10姿勢それぞれで、村人だけの絵とマネキンを重ねた絵を撮る
- `node scripts/fp-look.mjs`：一人称で見下ろした絵を撮る

## はまった所

- 腕がまっすぐなときに、肩の回りを手のひらの向きから決めると、肩ごとねじれてふくらむ。そこで肩は振るだけにして、手のひらは前腕と手首に任せた
- 一人称の確認でカメラを頭の中心に置くと、体の中に入って何も見えない。目は顔の前寄りに置くこと

## 限界（分かっていること）

- 腕を肩より高く上げると、肩と脇が大きくふくらむ。重みつきの回転で体を曲げているための限界で、VR で手を振り上げると目立つ
- 指の曲げ伸ばしと表情（口・目）は、アバターとつながっていない
- 大きさを目の高さで合わせるので、脚の長さの比率がアバターと違うと、膝の位置が少しずれる
- 公式が約束していない慣習に頼っている（`remote-player-<id>` の目印、描く間だけ隠すこと）。本体が変わると黙って壊れる可能性がある

## 本番で確かめること（版2の時点で未確認）

1. ござで村人になれる。自分の画面と他の人の画面の両方で、アバターが消えて村人が同じ動きをする
2. 歩く・走る・ジャンプ・座る・VR の手
3. 一人称で見下ろしたときの自分の体、鏡、名札の位置、影
4. 骨を読めないアバターのとき、「村人Aになれません」と出てアバターがそのまま残る（原因はコンソールの `[villager-a]` で始まる行）

## 育てる候補

- **肩のふくらみ**：腕を上げるときに鎖骨を先に回す（肩の支点を上げる）、脇の重みを2段に分ける
- **ほかの人物**：`making/` の手順で別の人を作り、ござごとに選べるようにする（村人B、店主など）
- **表情**：話し声（ボイスチャット）の大きさで口を動かす。公開 API があるかは未調査
- **変身の演出**：煙・光などで、変わる瞬間を見せる
- **案1（VRM 化）**：骨の重みを VRM の骨に移し、写真を UV 1枚に焼き直して、アバターとして導入する
