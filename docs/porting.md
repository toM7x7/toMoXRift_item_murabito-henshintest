# 変身を他のアイテムへ移す手順

村人Aで作った「着ると、その体に変身する」仕組みを、別のアイテムの体に移すときの手順です。最初の移植先は変形ゴリラロボ（`items/gorilla-robo`）で、そこで実際にこの手順を通しました。

## 仕組みを2つに分けてある

| 部分 | ファイル | 移すとき |
|---|---|---|
| 土台（体に依存しない） | `src/henshin/reader.ts`、`src/henshin/abilities.ts`、`src/pose-lib/` | そのままコピーする |
| 体（アイテムごと） | `src/wear.ts`、できることの一覧 | アイテムごとに書く |

### 土台がしていること

- 着ている人のアバターの骨格を探す（`remote-player-<id>` の目印。自分は目印の外の骨格。骨の名前か、骨格の形で読む）
- 描く直前にアバターの見た目を隠し、描き終わったら戻す。鏡の中の描画（描画の中の描画）を見分ける
- 骨を読む口を体に渡す（`AvatarReading`：骨の位置、骨の向き（体の左・上・前）、手の指と手のひらの向き、アバターの大きさ・目の高さ・休みの姿勢での腰と足首の高さ・脚と腕の長さ、骨盤の向き）
- キーと VR のボタンを受ける（`createAbilityInput`）

### 体が書くこと（`WornBody`）

```ts
interface WornBody{
 pose(r:AvatarReading,w:Wearer):void   // 描く直前：r を読んで自分の姿勢を決め、w.feet の上に自分を置く
 nested(inside:boolean,w:Wearer|null):void // 鏡の中の描画の始まり・終わり（鏡では頭を出す）
 hide():void                            // 描くものがない（読めていない・着ていない）
}
```

`pose` は描く直前に呼ばれます。シーンの行列はもう計算し終わっているので、体の `matrix` を自分で決め、`updateMatrixWorld(true)` まで済ませてください。

## 手順

1. `src/henshin/`（reader.ts・abilities.ts）、`src/pose-lib/`、確認用の `src/dev/vrm-avatar.tsx`・`src/dev-motion/`・`dev-assets/mannequin.glb` をコピーする（最後の3つは確認ページ用で、配布物には入らない）
2. 体の動かし方を決める（下の表）
3. `src/wear.ts` に `WornBody` を実装し、`AvatarReader` と組み合わせた `WearBridge` を作る（村人Aとゴリラロボの `src/wear.ts` が見本）
4. `Item.tsx` につなぐ：誰が着ているか（`useInstanceState`）、着る・やめる場所（`Interactable`）、毎フレーム `bridge.set(wearer)`、部屋を出た着用者を解放する処理、着ている間は体の普段の動き（NPC など）を止めること、やめたらその場から普段の動きに戻すこと
5. できることを書く：一覧（`Ability`）、押されたら部屋へ送る（`useInstanceEvent`）、届いたら着ている本人から来たものだけ動かす、本人の画面の右下にキーの案内
6. 確認ページに `?lab&wear` を足す（マネキン2体、歩かせる・姿勢を取らせる口）。確認スクリプトに `wear` の項目を足す

## 体の動かし方の決め方

| 化ける先 | やり方 | 例 |
|---|---|---|
| 人の形 | 骨を写す。骨盤・背骨・頭は体の軸どうしの相対回転、腕と脚は骨の向き（または手首・足首の位置を自分の腕と脚の長さに合わせて）で決める | 村人A（骨なしの体に回転を渡す）、ゴリラロボのロボット（手首・足首の位置を IK に渡す） |
| 人の形でないもの | 骨を写さない。体が持っている動きを、人の動きで操る。足元の動く速さと向き、頭の向き、手の高さなど、人がしたいことだけを読む | ゴリラロボのゴリラ（速さ→こぶしをついて歩く、止まる→座る、手を上げる→後ろ足で立って手を追う） |

人の形でないものに骨をそのまま写すと、たとえば2本足で背筋を伸ばして歩くゴリラになります。ゴリラロボでは、ゴリラの体はもともと持っている動き（四つ足の歩き、座る、ドラミング）を、人の動きで操るようにしました。

## 決めておくこと

- **大きさ**：他の人には体の本来の大きさで見せ、本人の一人称だけカメラ（アバターの目）に合わせる。一人称のカメラの位置は本体が決めるので、アイテムからは動かせない
- **一人称の頭**：本人の一人称では体の頭を描かない（鏡には映す）。頭がアバターの目より大きく前にある体は、頭がカメラの真下に来るよう体をずらす（ゴリラロボ）
- **キー**：本体が使うキーを避ける。公式の資料にあるのは W/A/S/D・Space・Q/E・G・H・Esc。本番では C と V も本体に取られた（2026-11-19）。村人Aとゴリラロボでは Z・X・R・F を使っている
- **VR のボタン**：A は本体のジャンプと座席から立つ、トリガーとグリップは掴む・使うに使われている。B（右）と Y（左）を使っている
- **1人1つ**：同じ人が2つの変身を同時に着ると、両方が同じアバターを隠して描こうとしてぶつかる。今は防いでいない（今後の課題）

## はまった所

- 1フレームが2回描かれることがある（確認ページでも起きた）。速さや向きのように前のフレームとの差で決めるものは、時刻が進んだときだけ更新する。同じ時刻でもう一度計算すると、動いた量 0 で向きが 0 に戻る
- 着た瞬間に、体の普段の動き（NPC のしぐさなど）が残っているとキーが効かない。着たときに消す
- 確認ページで一人称を撮るとき、カメラを頭の中心に置くと体の中に入って何も見えない。目は顔の前寄りに置く
