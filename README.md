# 村人A（items/villager-a）

GitHub: [toM7x7/toMoXRift_item_murabito-henshintest](https://github.com/toM7x7/toMoXRift_item_murabito-henshintest)

置いた場所のまわりで暮らす NPC の村人の XRift アイテムです。作り方は `fish-kit`（写真から作った魚と、シェーダーで計算する動き）と、それを手本にした `items/buncho` を人に広げたものです。骨もアニメーションクリップも使わず、写真から作った体を頂点シェーダーで関節ごとに曲げます。

## できること

| 場面 | 村人のふるまい |
|---|---|
| 何もしない | 立って見回す・片足に体重をかける・まばたき。ときどき、腰に手を当てる／手を前で組む／腰をそらして伸びる／頭をかく／手をかざして空を見る／首を回す |
| ときどき | 置いた場所から 1.3m 以内の別の場所へ数歩あるいて立つ |
| 人が近づく（約 3.4m 以内） | その人を見る。2.8m 以内に来ると、手を振るかお辞儀をする。後ろへ回られると、足踏みして向き直る |
| クリック（照準の案内は「話しかける」） | 話しかけた人のほうを向き、片手を上げて口を動かしながらひとこと言う。せりふは照準の案内に出る |
| 前のござをクリック（「村人Aになる」） | クリックした人が村人Aになる（下の「村人Aになる」）。もう一度ござをクリック（「村人Aをやめる」）でやめると、村人はその場に戻って、歩いて家へ帰る |

ふだんのしぐさと歩く先は共有時計（`useServerClock`）と配置 ID だけで決まるので、通信なしで全員の画面で同じになります。話しかけたことだけ `useInstanceEvent` で送ります（どのせりふか）。声は合成音です（音声ファイルなし）。浮かぶ名札や吹き出しは付けていません。

何人置いてもかまいません。置いた場所ごとにしぐさと歩く先が変わります。当たり判定（物理）はなく、すり抜けます。

## 村人Aになる（着る）

ござをクリックした人のアバターを、全員の画面で村人Aに見せます（`src/wear.ts`）。経緯・しくみ・育てる候補は [docs/henshin.md](docs/henshin.md)。

- アバターそのものは本体がいつもどおり動かします（歩く・VR の手・座る）。各自の画面が、描く直前にそのアバターの骨の向きを読み、アバターの見た目を隠し、同じ姿勢の村人Aを描きます。描き終わるとアバターの見た目は元に戻します。本体が持っているものは何も書き換えません
- 村人は、他の人の画面と本人の三人称では村人の大きさ（1.72m）、本人の一人称だけアバターの目の高さに合わせます（一人称のカメラが村人の目の位置に来る）。一人称の本人の画面では村人の頭を描きません（鏡には映る）
- 着ている人は、キーで村人のしぐさとせりふを出せます（Z 手を振る／X お辞儀／C ひとこと／V しぐさ。VR は Y でお辞儀、B でひとこと）。部屋の全員の画面で同じように動きます。画面の右下にキーの一覧と、言ったせりふが出ます
- 誰が着ているかだけ `useInstanceState` で共有します（1 体に 1 人。着ている人がいる間、ほかの人はござを使えず、話しかけることもできない）。着ている人が部屋を出ると、5 秒後に村人へ戻ります
- 骨の読み方は体操ステージと同じ、姿勢ラボの `selectActorRig`（`src/pose-lib`、ラボ 6584877 の写し）。骨を安全に読めないアバターでは、アバターをそのまま残し、ござの案内に「村人Aになれません」と出します

確認ページの `?lab&wear` に、自分と A さんの代わりの木のマネキン（`dev-assets/mannequin.glb`、配布物には入らない）を置いています。マネキンは体操の姿勢を取れます（`window.__villager.avatar`）。`node scripts/capture.mjs wear`（15 項目）、`node scripts/capture.mjs henshin`（13 項目）、`node scripts/wear-keys.mjs`（体操の姿勢ごとに、村人だけ／マネキンと重ねた絵）、`node scripts/fp-look.mjs`（一人称で見下ろした絵）。

分かっている限界：

- 腕を肩より高く上げると、肩と脇が大きくふくらむ（村人の体の作りの限界。VR で手を振り上げたときに目立つ）
- 指は 1 枚の板なので、指の曲げ伸ばしは映らない。表情（口・目）もアバターの表情とはつながっていない（まばたきだけ村人自身がする）
- 大きさは目の高さで合わせるので、脚の長さの比率がアバターと違うと、膝の位置が少しずれる

## 中身

- `public/villager_a.glb`：体の形と写真（約 19,800 三角形、1.1MB、テクスチャ 2048×2048）。`making/` のスクリプトが正面・後ろ・横の全身写真 3 枚と、顔の拡大 2 枚から作る
- `src/villager/model.ts`：読み込みと材質。頂点シェーダーが首・背骨・肩・ひじ・前腕のねじり・手首・股・ひざ・足首・あごを曲げ、フラグメントシェーダーが正面／後ろ／横の写真を貼り分ける。まぶたと口の中もここで描く
- `src/villager/rig.ts`：姿勢（数字の並び）をシェーダーの値に直す。腕は「上腕の向き＋ひじ＋ねじり」、脚は足首の位置から逆算する（足は地面に置いたまま、骨盤だけ動かせる）
- `src/villager/brain.ts`：時計から「いま何をしたいか・どこに立つか」を決める
- `src/villager/pose.ts`：しぐさ 1 つずつの姿勢
- `src/villager/actor.ts`：歩く・向き直る・人を見る・挨拶・会話をつなぐ
- `src/villager/audio.ts`：話し声（合成音）
- `src/words.ts`：画面に出る言葉（案内とせりふ 12 個）
- `src/Item.tsx`：人の位置・クリック・イベントのつなぎ込み

身長は 1.72m です。

## 開発

```bash
npm run dev
```

- `http://127.0.0.1:5323/`：公式の DevEnvironment で歩いて試す（2 人。クリックで話しかける）
- `http://127.0.0.1:5323/?lab`：確認用。時計を止めてコマ送りでき、姿勢を固定したり人を置いたりできる（`window.__villager`）

```bash
node scripts/capture.mjs
```

44 項目の確認と画像（`output/capture/`）。`python scripts/sheets.py` で場面ごとの一覧（`output/sheet-*.png`）ができます。開発サーバーが 5323 で動いていること。

- `node scripts/try-pose.mjs '{"名前":{...姿勢...}}'`：好きな姿勢を固定して 3 方向から撮る（新しいしぐさを書くとき用。姿勢の数字の意味は `src/villager/rig.ts` の先頭）
- `node scripts/thumbnail.mjs`：サムネイル
- `node scripts/smoke.mjs`：両ページのエラー確認

確認ページの `window.__villager.clay(n)` で、素の形（1）、どの写真がどこに貼られているか（2）、法線（3）、正面写真だけ（4）、横写真だけ（5）を見られます。

新しい人の作り方は `making/README.md`。

## 見た目の限界（分かっていること）

- 顔は正面・斜め・横とも人に見えますが、鼻の下からあごにかけては実物より影が濃く出ます（鼻の下の面は正面写真にも横写真にもほとんど写っていない）
- 腕を肩より高く上げると、肩と脇がふくらみます。しぐさはその範囲に入らないように作っています（`armsup` は確認用の姿勢）
- 目は動きません（視線は首で向ける）。口は開く幅を暗く塗っているだけで、歯や舌はありません
- 手の指は 1 枚の板です（指ごとには曲がらない）

### 着る機能の前提（2026-11-19、`@xrift/world-components` 0.66.1）

0.64.0 から 0.66.1 までの変更は Portal と DevEnvironment の瞬間移動だけで、アバター・掴む・視点には触れていない。着る機能は SDK が約束していない次のことに頼っています。

| 前提 | 公式の約束 | 確かめた所 |
|---|---|---|
| 他の人のアバターは `remote-player-<id>` の目印の下、自分のアバターはどの目印の外にもある骨格 | なし（本体の慣習） | 確認ページのマネキン。本番は体操ステージで動いた実績のみ |
| アバターの見た目を描く間だけ隠しても、本体が描く前に戻さない | なし | 確認ページ。本番未確認 |
| 一人称の視点か三人称か（`useViewpoint`） | あり（0.58.0） | 確認ページの代役 |
| 目の高さは `getAvatarHeight` / `getLocalAvatarHeight`（無ければ骨から測る） | あり（任意の関数） | 確認ページの代役 |

### 本番の部屋で確かめること（未確認）

1. 置ける。村人が見える（写真が貼られ、影が曲げた後の体の形で落ちる）
2. 照準を合わせると「話しかける」と出て、クリックでせりふに変わり、話し終わると戻る。長いせりふが切れずに読める
3. 照準時の本体側の強調表示が、見えない柱（直径 0.5m）として目立たない
4. 他の人が話しかけたとき、自分の画面でも村人がその人のほうを向いて話す（せりふは話しかけた本人にだけ出る）
5. 2 人の画面で、しぐさと歩く先がそろう（共有時計）
6. 声が聞こえる（最初のクリックの後から）
7. VR で近づいたときの顔の見え方、Quest での重さ（2 万三角形・2048 テクスチャ・1 体で写真を最大 7 回読む）
8. 平らでない床や段差の上に置いたとき（床の高さは見ていないので、歩く先でも置いた高さのまま）
9. 着る：ござで村人になれる。自分のアバターが消えて村人が同じ動きをする（自分の画面・他の人の画面の両方）。歩く・走る・ジャンプ・座る・VR の手

13. 着る：元のアバターが小さいとき、他の人から見て村人が 1.72m で、本人の一人称の体と目の高さが合っている
